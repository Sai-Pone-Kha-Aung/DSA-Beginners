# Data Structures and Algorithms (DSA) လေ့လာရန်

ဤ Project သည် Data Structures နှင့် Algorithms (DSA) အခြေခံများကို မြန်မာဘာသာဖြင့် လေ့လာနိုင်ရန် ရည်ရွယ်၍ ရေးသားထားခြင်းဖြစ်ပါသည်။ 

## ပါဝင်သော အကြောင်းအရာများ (Contents)

- **[Data Structures (ဒေတာတည်ဆောက်ပုံများ)](./data_structure/)**:
  - `array` (Array)
  - `string` (String)
  - `linked_list` (Linked List)
  - `stack` (Stack)
  - `queue` (Queue)
  - `hash_table` (Hash Table)
  - `tree` (Tree)
  - `bst` (Binary Search Tree)
  - `graph` (Graph)

- **[Algorithms (အယ်လဂိုရစ်သမ်များ)](./algorithm/)**:
  - `linear_search` (Linear Search)
  - `binary_search` (Binary Search)
  - `bubble_sort` (Bubble Sort)
  - `selection_sort` (Selection Sort)
  - `insertion_sort` (Insertion Sort)
  - `bfs` (Breadth-First Search)
  - `dfs` (Depth-First Search)

- **[Recursion (ကိုယ့်ကိုယ်ကို ပြန်ခေါ်ခြင်း)](./recursion/)**:
  - Recursion အခြေခံများနှင့် ပြဿနာဖြေရှင်းနည်းများ

- **[Slides (ဆလိုက်များ)](./slides/)**:
  - သင်ခန်းစာများအတွက် အသုံးပြုထားသော ရှင်းလင်းချက် ဆလိုက်များ (Presentation Slides)

## ဘယ်ကစပြီး လေ့လာမလဲ? (How to start learning?)

1. ပထမဦးဆုံးအနေဖြင့် `data_structures` ဖိုင်တွဲထဲမှ အခြေခံ ဒေတာတည်ဆောက်ပုံများ (ဥပမာ - Array, String, Linked List, Stack, Queue) ကို စတင်လေ့လာသင့်ပါသည်။
2. လိုအပ်ပါက `recursion` အကြောင်းကိုလည်း လေ့လာထားပါ။
3. ၎င်းနောက် Tree, Graph စသည့် ပိုမိုရှုပ်ထွေးသော ဒေတာတည်ဆောက်ပုံများကို လေ့လာပါ။
4. နောက်ဆုံးတွင် `algorithms` ဖိုင်တွဲထဲမှ ရှာဖွေခြင်း (Searching) နှင့် စီစဉ်ခြင်း (Sorting) အယ်လဂိုရစ်သမ်များကို လေ့လာပါ။

## How to run

Code ကို run ရန်အတွက် သက်ဆိုင်ရာဖိုင်များကို မိမိအသုံးပြုနေကျ Python Version ဖြင့် ဖွင့်၍ စမ်းသပ်နိုင်သည် (ဥပမာ - `python algorithm/bubble_sort/bubble_sort.py`)။
